# Análise Financeira e Operacional da Azul Linhas Aéreas

## Sobre o projeto

Este projeto acadêmico tem como foco a coleta e organização de dados
financeiros e operacionais da Azul S.A., empresa do setor de transporte
aéreo.

A proposta é utilizar informações públicas da empresa para desenvolver
competências em coleta, tratamento e visualização de dados.

O período definido para a coleta das informações compreende os anos de
2021 a 2025.

## Objetivo

Investigar informações relacionadas à situação financeira da Azul S.A.,
utilizando dados públicos disponibilizados pela empresa e por fontes
institucionais.

O projeto também busca desenvolver habilidades práticas de coleta,
tratamento e organização de dados para análises futuras.

## Empresa analisada

- Empresa: Azul S.A.
- Setor: Transporte aéreo
- Atividade econômica: Transporte aéreo regular de passageiros
- CNAE: 5111-1/00

## Fontes dos dados

As principais fontes de dados definidas para o projeto são:

- Comissão de Valores Mobiliários (CVM).
- Relatórios de resultados da Azul S.A.

Entre os documentos considerados estão:

- Balanço Patrimonial.
- Demonstração do Resultado do Exercício (DRE).
- Demonstração dos Fluxos de Caixa.
- Demonstração das Mutações do Patrimônio Líquido (DMPL).
- Demonstração do Valor Adicionado (DVA).

### 1. Definição do tema

Escolha da Azul S.A. como empresa de estudo dentro do setor de
transporte aéreo.

Etapa destinada à obtenção dos dados financeiros e operacionais da
empresa.

### 5. Tratamento dos dados
